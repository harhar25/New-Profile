# Portfolio pages and sections

Each homepage section is composed independently in `components/HomeSections.tsx`. Replace a section component or give it a dedicated CSS module to change its design without rewriting the page.

The portfolio uses a gold HM monogram in `app/icon.svg`, a multi-size `app/favicon.ico`, and `app/apple-icon.png` for browser tabs and phone shortcuts. Open Graph and Twitter PNG cards use the editable source in `public/brand/social-card.svg`. Next's file-based metadata publishes these images across the site. `NEXT_PUBLIC_SITE_URL` can set a custom domain for absolute preview URLs; otherwise the Vercel production/deployment URL is used, with localhost for local builds.

`PortfolioShell.tsx` shares navigation, profile data, and the contact popup across the public pages. `PortfolioFooter.tsx` is their shared contact section. Admin and API routes remain outside this shell.

Experience adapts the supplied Glyph Portal (© 2026 Christian Katzmann, MIT; attribution retained in the component). A warm paper poster reads BUILD through a clipped bronze system diagram; native scrolling moves the camera into measured letter ink and reveals a chronological timeline made from the saved experience records. Hover, tap, or arrow keys choose the entry letter before scrolling. The skip link leads directly to stable `#experience-details`. Reduced motion, short viewports, unavailable canvas metrics, and stalled rendering use ordinary reading flow. The following work corridor remains after the complete timeline.

`PortfolioNavbar.tsx` adapts the supplied AnimeNavBar design into a floating charcoal-and-gold pill. Real Next links expose Home, Projects, Skills, and the automation playground. The highlighted tab follows the route; a generated transparent illustration of Harold in `public/images/harold-nav-mascot.png` points down at it, and follows More or Contact while either is open. The source portraits remain unchanged. CSS animates the indicator, mascot travel, and a small bob; reduced motion disables these effects. Mobile tabs retain readable labels. More opens a scrollable section index with Escape, outside-click dismissal, focus management, inert background content, and scroll locking. Shared navigation clearance keeps anchor targets and the landing hero below the raised mascot.

The homepage Projects and Skills links adapt the supplied Glass Folder Cards design through `ui/PortfolioFolder.tsx` and its CSS module. Warm smoked glass and pale sage glass hold real screenshot and skill previews. Hover or keyboard focus lifts the files; clicking or pressing Enter/Space opens the folder and exposes preview links. Escape or moving focus out closes it. Each folder has a separate, always-visible link to its full page. The skill count and preview lists use the shared profile data. Responsive geometry uses CSS, and reduced motion disables transitions and pointer tilt.

The shared footer exposes public LinkedIn and GitHub links in new tabs, with default profile URLs used when saved social fields are empty. Its Email control uses `EmailReveal.tsx` and `PortfolioFooter.module.css` to show a selectable address in a brief wobbling popup on hover, keyboard focus, or touch. Escape, outside presses, and leaving the control dismiss it; reduced-motion preferences disable the wobble. Email addresses are displayed as text without mailto navigation, including in the contact dialog.

Orbit combines contextual portfolio retrieval with a conversational AI prompt, strict structured replies, trusted page/contact actions, and bounded memory in the current browser tab. Its labelled guide mode remains useful when AI is unavailable. See `docs/ROBOT_ASSISTANT.md` for setup, memory behavior, provider limits, and validation.

Use `usePortfolio()` inside shell content to read the saved profile and open the contact popup. Projects and Skills use the same existing profile data and preserve the original project links, n8n workflow download/research, and all skill names and proficiencies. Projects uses a compact illustrated feature grid inspired by the owner-selected uiable Feature Highlights Grid reference. Skills groups its category cards into four overlapping chapters: Automation & CRM, Web & Connections, AI & Reporting, and Support & Delivery. Native page scrolling pins each chapter while the next layers over it; a final reading interval precedes the playground callout and footer. Chapter links jump to markers in normal document flow. A ResizeObserver adjusts the sticky offset for tall chapters so every skill can scroll into view on narrow screens and at browser zoom. Extra categories are retained in additional chapters. Reduced motion and print use a regular vertical layout.

The automation playground is linked from the menu, Projects, and Skills. Its n8n-, GoHighLevel-, Make-, and Zapier-inspired modes have separate starter layouts and load a fresh workflow when switched. Visitors can add/configure/remove nodes, drag entire cards or their grips with a mouse or touch, pan by dragging empty canvas space, drag wires from output to input ports (or click ports/use the connection form), remove connections, zoom, and run/stop a browser-only sample simulation. Card clicks open settings; dragging moves a node without opening settings, and its wires follow. Focused cards and grips support arrow keys for 10px moves and Shift+arrow keys for 30px moves. Node positions stay within the canvas and respect its zoom. Pointer cancellation, Escape, or losing focus ends a card/pan gesture. Disconnect all clears wires while keeping the steps for manual building. A live wire snaps to nearby inputs, highlights valid targets, marks invalid targets, and scrolls the canvas near its edges during dragging. Escape, pointer cancellation, and dropping on empty canvas cancel the wire. Sample data, tags, score filters, email previews, CRM stages, and spreadsheet previews follow the actual directed graph. The engine rejects disconnected steps, loops, duplicate inputs, and invalid data. No live integrations or credentials are used, and edits last for the current page visit. Run `npm run test:automation` for graph and execution tests.

The Projects page includes the 15 original `Screenshot*.png` uploads plus 48 distinct additional images from `public/Automation`, for 63 public archive frames before the system case studies. Its curated manifests are `lib/projectScreenshots.ts` and `lib/automationScreenshots.ts`. Five byte-identical Automation images reuse existing archive entries; the two dot-prefixed images use their existing public copies in `uploads` because Next cannot serve dot-prefixed files. The gallery adapts the supplied scatter/line/circle/arc card choreography using CSS transitions, with 12 thumbnails per set, previous/next controls, a full screenshot preview, and original-image links. Native page scrolling is retained. A text index makes every image easy to select, and reduced-motion preferences disable transitions and the automatic introduction.

The homepage features the English listening certificate immediately after the introduction. Its preview is a direct raster rendering of `public/C1_certificate/Harold_jey_N_Madjos_C1_certificate-listening.pdf`; view and download actions link to that original PDF. The section reports Exam English, 24 July 2026, CEFR C1 Advanced listening, and the certificate's self-assessment qualification without extending the result to speaking, reading, or writing.

The landing hero adapts the supplied Sculpture Hero by guglielmogiannattasio.it. `ShaderHero.tsx` retains the public section anchors, Harold's name, and working Projects and Skills links, while `useLiquidSculpture.ts` integrates the attributed WebGL2 engine in `ui/liquid-particles-engine.ts`. A metallic sculpture flows into GPU particles under the pointer or touch, then returns to its image. Desktop and portrait assets are served locally from `public/images/hero`; their source URLs are documented alongside them. The Light/Dark control switches the artwork, warm paper/charcoal surfaces, gold/bronze typography, and buttons together. It starts from the browser's color preference and remembers an explicit choice in local storage, with an in-memory fallback when storage writes fail. Styling is scoped to the hero; the browser's overscroll surface follows its mode.

Particle sampling, texture sizes, and backing resolution are bounded (up to 120,000 particles on desktop and 60,000 on lower-power devices). Motion pauses behind the entrance, offscreen, in background tabs, with the pause control, and while a menu/contact dialog is open. Reduced motion keeps a crisp still frame. The local image covers loading, unavailable WebGL, float-rendering failures, and context loss; restoration creates a fresh canvas and renderer. Image failure leaves a simple system illustration. Theme changes reuse the engine, and cached-mode returns recover from interrupted image loads. Native touch scrolling and existing navigation remain available.

The work corridor adapts the owner-supplied ImageStreamHero geometry in the existing `#story` section, between Experience and Credentials. It uses local workflow and website screenshots from `public/uploads`, landscape cards that contain the full image, CSS perspective, and a pause control. Every image gets a card on each rail, including collections larger than ten images. Motion stops offscreen, in background tabs, while a menu/contact dialog is open, and for reduced-motion preferences. The former WebGL gallery remains available in `ui/3d-gallery-photography.tsx` but is no longer mounted here.
